# FUTURE_DS_01 - Business Sales Performance Analytics

**Future Interns - Data Science & Analytics Track**
Task 1: Business Sales Performance Analytics

## Overview

Analysis of the Sample Superstore dataset (9,994 retail order-line transactions,
2014–2017) to identify revenue trends, top-selling products, high-value
categories/sub-categories, and regional performance - and to surface what is
driving margin loss across the business.

## Tools Used

- **Python** (pandas, matplotlib) - written and run in **Spyder IDE**
- Dataset: [Sample Superstore](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) (Kaggle)

## Repository Contents

| File | Description |
|---|---|
| `analysis.py` | Full analysis script — loads the data, computes KPIs, and generates all charts |
| `Sample - Superstore.csv` | Source dataset |
| `Business_Sales_Performance_Analytics_Report.pdf`  | Client-ready report with insights and recommendations |
| `charts/` | Chart images referenced in the report (generated by `analysis.py`) |

## How to Run

1. Open `analysis.py` in Spyder (or any Python IDE)
2. Make sure `Sample - Superstore.csv` is in the same folder
3. Run the script — it prints KPIs and analysis tables to the console and
   displays each chart in turn

**Requirements:** `pandas`, `matplotlib`

```bash
pip install pandas matplotlib
```

## Key Insights

- **$2.30M revenue, $286K profit (12.5% margin)** across 5,009 orders, 2014–2017,
  with 2017 up 20.4% year-on-year
- **Furniture is barely profitable (2.5% margin)** — driven almost entirely by
  losses on Tables (-8.6% margin) and Bookcases (-3.0% margin)
- **Discounts above 20% are unprofitable as a group**, costing roughly $135K in
  profit — the clearest lever for margin improvement
- **Texas, Ohio, Pennsylvania, and Illinois are net loss-making states** despite
  solid sales volumes
- Technology and Office Supplies are the strongest categories; Copiers, Paper,
  and Labels are the highest-margin sub-categories

Full analysis, charts, and recommendations are in the accompanying report.
